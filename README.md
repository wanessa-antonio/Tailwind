# ⚡ Projeto React com Vite e Tailwind CSS

Aplicação desenvolvida utilizando Vite para configuração inicial do projeto, React como framework principal e Tailwind CSS para estilização.

---

## 📌 Sobre o projeto

Este projeto foi criado com o objetivo de praticar a criação de aplicações modernas utilizando ferramentas atuais do ecossistema front-end.

---

## 🛠️ Tecnologias utilizadas

- Vite  
- React  
- JavaScript (ES6+)  
- Tailwind CSS  

---

## ✨ Funcionalidades

- Estrutura baseada em componentes  
- Estilização com classes utilitárias do Tailwind  
- Ambiente de desenvolvimento rápido com Vite  
- Código organizado e escalável  

---

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para:

- Praticar configuração de projetos com Vite  
- Aprimorar conhecimentos em React  
- Trabalhar estilização moderna com Tailwind CSS  
- Aplicar boas práticas na organização de componentes
